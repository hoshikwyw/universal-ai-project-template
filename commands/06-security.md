# 06 — Security review

Follow `.agents/security-engineer.md` and read security context and architecture. Review only the authorized project/change. Identify assets, trust boundaries, threats, and relevant secure coding concerns. Perform only safe local checks that are available and authorized; no intrusive scans or production probing. Report evidence-backed findings, severity/confidence, suggested remediation, and remaining unknowns. Do not change code unless separately approved.
